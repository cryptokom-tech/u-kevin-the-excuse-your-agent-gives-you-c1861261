> Sorry — I tried to fix the bug, but the rest of the code is leaning on it now, and the whole app falls over without it.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
